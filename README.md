# NHL Hockey 96 for DOS

> **🤝 Making a mod, hack, port or other derivative work from this repo? You must credit me and everyone credited in this repo, clearly, in your own repo and in every release. See [Credits and derivative works](#credits-and-derivative-works).**

> **📀 The retail EXE is not included.** Copy `HOCKEY.EXE` from your own NHL 96 install to `lst/HOCKEY.EXE` (gitignored), or pass its path to `./build.sh`; the build checks its SHA-1 and size and tells you exactly what it needs when it is missing. The IDA listing is not in the repo either: keep your own copy at `lst/HOCKEY.EXE.lst` if you have one. Patch files are never committed.

> **📀 The other game files are needed to run the game.** This repo builds `HOCKEY.EXE` only; the game's data (`*.VIV`, `*.FSH`, `*.ASF`, `*.QFS` and the rest of the install) is not here.

## 🚧 Current Status

- **The whole EXE builds from NASM source, byte-identical** (`./build.sh` prints MATCH): 112 code files, 134 data files and the two
  small objects, with a label for every address and the LE fixup tables regenerated by the linker. Only the DOS/4GW extender parts
  and the LE header fields are taken from your EXE. The tools and layout are NHL95PC's.
- Names: 297 of 7,845 cross-file symbols so far (library names, and NHL95PC names where the code matches). Naming the rest, file by
  file, is the work in progress (`SEGMENT_AGENT.md`, `docs/PLAN.md`).
- This is a **disassembly only**: labelled 32-bit x86 assembly that reassembles byte-identical. There is no C decompilation or compiler matching.

## Lineage

NHL '96 PC is based on [NHL95PC](https://github.com/abdulahmad/NHL95PC) and [NHL96Genesis](https://github.com/abdulahmad/NHL96Genesis). Names come from those repos, matched by purpose, not by identical code, and the earlier game's name wins: 95PC (whose names already carry 93G/94G) first, then 96G for what is new in 96; a 96G name inherited from an earlier Genesis game beats a 95PC name made up from behaviour. See SEGMENT_AGENT.md.

## Layout

- `src/engine/`, `src/front/`, `src/lib/`: the code, one file per module, in NHL95PC's folders where the module matches.
  `src/data/`: data and BSS. `src/cseg02/`, `src/dseg03/`: the two small objects. `src/segments.txt`: the link order.
- `src/inc/`: `hockey.inc` (included by every file), `x86enc.inc` (the `LD` macro), `symbols.inc` (generated index).
- `segmap96pc.json` and `EXE_SEGMAP96PC.md`: every segment's range, file and note. `docs/name_map.csv`: every name and its evidence.
- `tools/build/`, `tools/names/`: the build, rename and matching tools (docs/ASM_BUILD.md).

## Build

Needs NASM 2.15+ and Python 3. `./build.sh` ends with `MATCH: build/HOCKEY.EXE is byte-identical to the retail HOCKEY.EXE`. See [docs/ASM_BUILD.md](docs/ASM_BUILD.md).

## Running the game on a modern PC (SDL2 port)

The branch `sdl2-port` runs the game's own 32-bit code natively, with DOS, BIOS, sound, video and input hardware emulated by the host
in `port/`. Build and details: [docs/SDL2_PORT.md](docs/SDL2_PORT.md). `src/` is untouched, so `./build.sh` still ends with `MATCH`.

```
make sdl2                 # build/hockey-linux (needs gcc-multilib and libsdl2-dev:i386)
NHL96_ROOT=/path/to/game  # installed NHL 96 data files
build/hockey-linux
```

The host loads `lst/HOCKEY.EXE` (or `NHL96_EXE`) at a relocated address so it does not overlap VGA memory.
